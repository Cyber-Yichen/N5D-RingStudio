# 1.1 设计与接口方案

## 界面

沿用纸白 #F5F7FC、墨蓝 #24364D、夜蓝 #16243B、灰蓝 #6E7E91、珊瑚 #D85371。标题使用 sans-serif-medium，正文 sans-serif，版本与色值使用 monospace。新的彩色光环图标作为唯一品牌图形。

横屏 1600×720 为适配基准。外边距 20 px、主卡片 R40、屏幕轮廓约 R60；所有左侧内容均留出挖孔安全区。顶部分类与内容共用 56 px 额外左边距。关于页使用与主页相同的全屏双栏：左侧滚动信息卡片，右侧品牌、版本及操作。返回不停止灯效。

右侧卡片的按钮区域统一采用 24 px 内边距和 24 px 按钮间距，左右、底边、横向与纵向间隔相同。主界面与关于页面共用 StudioUi 按钮样式。版本号直接放在应用 Logo 下方居中；主界面开关灯合并为同一按钮。更新日志首次打开本版本自动显示，关于页面可随时重新打开。

单色编辑器加入随机按钮，立即更新色轮、明暗区域、HEX 和色块；确认后才写入灯效。更新按钮打开 GitHub 最新正式发布页，不增加网络权限、静默下载或安装功能。

## 本机接口

公开独立的 Messenger 绑定服务，实际灯光服务保持不导出。协议版本与应用版本分离。能力查询和状态查询无需控制权；写操作需用户开启本机接口，并取得单一控制会话。

能力包括内置效果参数、独立 Logo、按物理顺序的 24 RGB 与 24 白灯帧、原始 96 通道帧、独立 RGB/白灯亮度。RGB 帧使用 RGB 顺序和顺时针物理位置，调用者无需理解芯片通道。原始帧保留给已了解硬件映射的高级应用。所有值限于灯光控制，不开放任意驱动寄存器、文件、Shell 或分区操作。

以系统传递的调用 UID 与随机会话标识确定拥有者，单一会话防止互相覆盖。会话默认 10 秒、可选 2～60 秒；帧与心跳续租，客户端死亡、超时、停用接口、全关或退出均回收控制。客户端归还、失联或超时时默认恢复接管前的本地灯效，也可显式选择关灯。主界面选择灯效立即接管，Logo 操作保持环灯不变。

帧上限 25 fps，与驱动现有调度一致；只缓存最新有效帧，不建立无限队列。请求逐个确认，回复包含请求编号、状态、错误码和协议版本。协商能力避免调用者假设所有设备具有相同映射。接口默认关闭，开启后允许任何本机应用控制灯光，不要求调用者拥有 Root 或与本程序同一签名。
